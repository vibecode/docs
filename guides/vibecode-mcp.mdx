**Vibecode has an MCP server, so you can use it from the AI tools you already use.** Connect it once, sign in to your Vibecode account, and ask your AI for an app. Vibecode's agent builds the app, tests it, and saves it to your account. You can keep working on it in Vibecode on the web or in the Vibecode iPhone app.

The server URL is:

```
https://api.vibecodeapp.com/mcp
```

## What You Need

- An AI app that supports MCP servers with sign-in. ChatGPT, Claude, Claude Code, Codex, Cursor, VS Code and Gemini CLI all do.
- A Vibecode account. You can create one on the sign-in page when you connect. New accounts that sign up with Google or Apple get their [first app build free](/getting-started/plans-and-credits). After that, builds and changes use [credits](/getting-started/plans-and-credits).

## Connect Vibecode

### ChatGPT and Claude

- **ChatGPT:** open [Vibecode in ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6ac19ea1f9488191a0a16ee661f57e60) and connect it, then sign in to Vibecode.
- **Claude:** open **Customize**, then **Connectors**, and add Vibecode. If it isn't in the directory for you yet, add it as a custom connector with the server URL. [Use Vibecode in Claude](/guides/vibecode-in-claude) has every step.

### Coding Tools and Other Apps

        claude mcp add --transport http -s user vibecode https://api.vibecodeapp.com/mcp

        `-s user` makes Vibecode available in every folder, not just the current one.

        In Claude Code, run `/mcp`, select **vibecode**, then select **Authenticate**. Your browser opens the Vibecode sign-in page. Sign in and select **Allow**.

      </Step>
      <Step title="Sign in">
        Codex opens the Vibecode sign-in page. Sign in and select **Allow**. To sign in again later, run `codex mcp login vibecode`.
      </Step>

## What Your AI Can Do

Ask in plain English, for example:

- *"Using Vibecode, build me an iPhone app to track my workouts, with a weekly summary."*
- *"Build me a web app to plan my meals for the week."*
- *"Show me my Vibecode apps."*
- *"Make the buttons in my workout app blue and add a rest timer."*
- *"Why did the last build of my habit tracker fail?"*

A build usually takes about 10 minutes. Your AI can wait for it and tell you when the app is ready, with links to open it in Vibecode, see it on your phone in the Vibecode iPhone app, or publish it to the App Store.

What Vibecode offers depends on the app. Other apps means Claude Code, Codex, Cursor, VS Code, Gemini CLI and any other MCP app. They show no app card, so your AI gives you links instead.

| | ChatGPT | Claude | Other apps |
| --- | --- | --- | --- |
| Build and change apps, follow builds | Yes | Yes | Yes |
| A live app card in the chat | Yes | Yes | No |
| See what the agent did, read the code and logs, restore an earlier version | Yes | No | Yes |
| Rename, copy or delete apps | Yes | No | Yes |
| Run commands in the app's workspace | No | No | Yes |

`run_command` runs a shell command in the app's workspace, a Linux sandbox in the app's folder, and returns the output. Use it to run tests, check versions or install a package. A command stops after 45 seconds.

## Your Account and Your Data

- Your AI only gets access after you sign in and select **Allow**. The sign-in page names the app asking for access.
- It can see your Vibecode apps and their code. Your app's keys stay hidden in files, logs and command output.
- Builds and changes use your Vibecode credits, the same as building in Vibecode.
- To learn what Vibecode receives and sends back, see [Vibecode in ChatGPT and Claude](https://www.vibecodeapp.com/privacy) in our Privacy Policy.

## Disconnect

Remove the server in your app's MCP or connector settings. In the command-line tools:

```bash
claude mcp remove vibecode -s user
codex mcp remove vibecode
gemini mcp remove -s user vibecode
```

Your apps stay in your Vibecode account.

## Troubleshooting

- **The sign-in page doesn't open.** In Gemini CLI, run `/mcp auth vibecode`. In VS Code, select **Allow**, then **Open**. In Cursor, select **Authenticate** next to Vibecode. In Codex, run `codex mcp login vibecode`.
- **Claude Code shows two Vibecode servers.** Connectors you add in Claude also appear in Claude Code, as **claude.ai Vibecode**, with Claude's tools. The one you add with `claude mcp add` has all the tools in the table above.
- **A build doesn't start.** Your account may be out of credits. Your AI tells you why, and you can add credits or choose a plan in Vibecode.

## Vibecode MCP or Vibecode CLI?

With the MCP, Vibecode's agent writes the app and your AI directs it. With the [Vibecode CLI](/vibecode-cli), your own agent writes the code and uses Vibecode's sandboxes, databases, sign-in and hosting to run and publish it.
