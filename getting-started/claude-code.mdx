**Claude Code is Anthropic's AI coding agent: you describe what you want in plain English, and it reads your project, edits the files, and runs commands until the job is done.** To use it on your own computer, install it with one command, run `claude` in your project folder, and sign in with a paid Claude plan (Pro is $20/month, or $17/month billed yearly). Or skip the setup: Vibecode runs Claude Code for you in a cloud sandbox, so you can build native iPhone, Android, and web apps from your browser or phone without a terminal or a Claude subscription.

## Claude Code at a Glance

| | |
|---|---|
| **What it is** | An agentic coding tool. It plans, edits files across your project, runs terminal commands, and checks its own work. |
| **Made by** | Anthropic |
| **Where it runs** | Your terminal, VS Code, Cursor, JetBrains IDEs, the Claude desktop app, and the web |
| **Works on** | macOS 13+, Windows 10 (1809+) or Windows Server 2019+, Ubuntu 20.04+, Debian 10+, Alpine 3.19+. Needs 4 GB+ RAM. |
| **Install** | `curl -fsSL https://claude.ai/install.sh \| bash` (Mac, Linux, WSL) or `irm https://claude.ai/install.ps1 \| iex` (Windows PowerShell) |
| **Is it free?** | No. It needs a Claude Pro, Max, Team, or Enterprise plan, or a pay-as-you-go Claude Console (API) account. |
| **In Vibecode** | Nothing to install. Claude Code runs in your project's cloud sandbox and is paid for with Vibecode credits. Your first app build is free. |

## Is Claude Code Free?

No. The free Claude.ai plan doesn't include Claude Code. You need one of these:

| Option | Price | Notes |
|---|---|---|
| Claude Pro | $20/month, or $17/month billed yearly ($200/year) | Cheapest way to use Claude Code yourself. Usage limits are shared with Claude chat. |
| Claude Max | From $100/month | Higher usage limits for heavy coding sessions |
| Claude Team | $25/seat/month ($20 billed yearly) for Standard seats | Premium seats cost more |
| Claude Console (API) | Pay as you go | You pay per token from prepaid credits |
| **Vibecode** | **First app build free**, then credits ([plans from $20/month](https://www.vibecodeapp.com/pricing)) | Claude Code runs in the cloud. No Claude subscription, no install. |

Prices are from [claude.com/pricing](https://claude.com/pricing) as of October 2026. Anthropic changes plans from time to time, so check there before you buy.

## How to Install Claude Code

Open a terminal and run the command for your system:

<CodeGroup>
```bash macOS, Linux, WSL
curl -fsSL https://claude.ai/install.sh | bash
```
```powershell Windows PowerShell
irm https://claude.ai/install.ps1 | iex
```
```batch Windows CMD
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```
```bash Homebrew
brew install --cask claude-code
```
```powershell WinGet
winget install Anthropic.ClaudeCode
```
```bash npm (Node.js 22+)
npm install -g @anthropic-ai/claude-code
```
</CodeGroup>

Then open a **new** terminal window and check it worked:

```bash
claude --version
```

It prints a version number followed by `(Claude Code)`. If your shell says `claude` isn't found, the install folder isn't on your PATH yet. Run `claude doctor` for a diagnosis.

<Tip>The native installer (the first three commands) updates itself in the background. Homebrew, WinGet, and npm installs don't, so update them yourself.</Tip>

### Install Claude Code on Windows

You can run Claude Code natively on Windows or inside WSL:

1. Open **PowerShell** (your prompt starts with `PS C:\`) and run `irm https://claude.ai/install.ps1 | iex`. You don't need to run it as Administrator.
2. Optional but recommended: install [Git for Windows](https://git-scm.com/downloads/win). With it, Claude Code uses Git Bash for shell commands. Without it, Claude Code uses PowerShell.
3. Open a new terminal and run `claude`.

Prefer Linux tools? Open your WSL distribution and run the macOS/Linux command there instead. If you see `'irm' is not recognized`, you're in CMD, not PowerShell. Use the Windows CMD command above.

## How to Use Claude Code

1. **Open a terminal in your project folder:** `cd path/to/your-project`
2. **Start it:** type `claude` and press Enter
3. **Sign in:** the first time, it opens your browser to log in with your Claude or Console account
4. **Ask in plain English:** for example, `what does this project do?` or `add a dark mode toggle to the settings screen`
5. **Approve changes:** Claude Code shows each edit or command and asks before running it (press `Shift+Tab` to change how much it can do without asking)
6. **Keep going:** describe the next change, or say `commit my changes with a descriptive message`

Commands you'll use most:

| Command | What it does |
|---|---|
| `claude` | Start an interactive session in the current folder |
| `claude "fix the build error"` | Start a session with a first prompt |
| `claude -c` | Continue your most recent conversation in this folder |
| `claude -p "explain this function"` | Ask a one-off question and exit |
| `/clear` | Clear the conversation (start fresh between tasks) |
| `/init` | Create a `CLAUDE.md` file with notes about your project that Claude reads every session |
| `/help` | List available commands |
| `/exit` | Quit |

## How to Use Claude Code in VS Code

1. In VS Code (version 1.94 or later), open the Extensions view with `Cmd+Shift+X` (Mac) or `Ctrl+Shift+X` (Windows/Linux)
2. Search for **Claude Code** (published by Anthropic) and click **Install**
3. Open a file, then click the **Spark** icon in the top-right of the editor to open the Claude Code panel
4. Click **Sign in** and finish logging in in your browser
5. Type your request in the panel. Claude sees the text you have selected, and shows its changes as diffs you can accept or reject.

The same extension installs in Cursor and other VS Code-based editors. You still need a paid Claude plan or a Console account.

## How to Vibe Code an App with Claude Code

"Vibe coding" means building by describing what you want and judging the result, instead of writing the code yourself (more in [What is vibe coding?](https://www.vibecodeapp.com/what-is-vibe-coding)). Claude Code is good at it, but on your own computer you also need everything around the code:

| To ship a real app you need | Claude Code on your computer | Claude Code in Vibecode |
|---|---|---|
| A place to run the agent | Your terminal or editor, plus a Claude plan | A cloud sandbox per project, opened from your browser or the Vibecode iPhone app |
| A live preview | You run the dev server yourself | Built in: a live web preview, your phone, or a cloud iOS Simulator |
| A native iPhone app (Swift) | A Mac with Xcode | No Mac needed. [Built on cloud Macs](/getting-started/native-ios-apps). |
| Testing | You ask for tests and run them | The agent [tests the app it just built](/features/agent-testing) and fixes what it finds |
| Database, login, and file storage | Set up Supabase, Firebase, or your own | [Vibecode Cloud](/features/vibecode-cloud), added with one prompt |
| AI and data APIs | Your own API keys and billing | [Built-in integrations](/integrations/index), paid with credits |
| App Store publishing | Signing, Xcode or EAS, and App Store Connect yourself | [Publish from the web app](/getting-started/deploy-app-store) |
| Your code | On your machine | [Download it](/getting-started/download-code) or [connect over SSH](/getting-started/export-ssh) |

Already happy in your own terminal? The [Vibecode CLI](/vibecode-cli) gives your local Claude Code (or Cursor, Codex, or Gemini) access to Vibecode's sandboxes, backends, integrations, and deployments.

## How Vibecode Runs Claude Code for You

Every Vibecode project gets its own cloud sandbox, and Claude Code is the agent that works in it. When you send a prompt:

1. Claude Code plans the change and writes the code: **Swift and SwiftUI** for an [iOS app](/getting-started/native-ios-apps), **React Native and Expo** for a Mobile app (iOS and Android), or a **web app**
2. It adds what the app needs, such as a [database and login](/features/backend-auth), [image generation](/features/image-generation), [sound](/features/sound-generation), and [haptics](/features/haptics)
3. It opens your app, taps or clicks through what it changed, and fixes what it finds ([agent testing](/features/agent-testing))
4. You see the result in the live preview and keep chatting to change it

Pick the model in the prompt box's model picker. **Claude Opus 5.5** is the default for new apps, and you can switch to other Claude models or to GPT models. Usage comes out of your [Vibecode credits](/getting-started/plans-and-credits), so you don't need a Claude subscription or an API key.

## Best Practices for Using Claude Code

These work in your terminal and in Vibecode:

1. **Plan before building.** Ask for a plan first ("plan how you'd add a checkout flow, don't write code yet"), review it, then say "go". This catches wrong assumptions before they cost you time and credits.
2. **Be specific.** "Fix the login bug where users see a blank screen after a wrong password" beats "fix the bug". Name the screen, the action, and what should happen.
3. **Give it lasting context.** Put your conventions and decisions in `CLAUDE.md` (run `/init` to start one) so you don't repeat them every session.
4. **Clear context between tasks.** Use `/clear` (or start a new chat in Vibecode) when you switch to an unrelated task. Long, mixed conversations produce worse results.
5. **Show, don't just tell.** Attach screenshots or design mockups, and point to the exact files or screens you mean.
6. **One feature at a time.** Build the core, check it works, then add the next thing.
