Google Gemini 3.5 Flash is Google's fast and cost-efficient workhorse model. It handles chat, coding, and agentic tasks with quick responses at a fraction of the cost of Gemini Pro.

Like the Pro model, it accepts text, images, video, audio, and PDFs as input, so it can analyze almost any content.

## Best For

- Fast AI chat
- Image, video, and audio analysis
- Document and PDF analysis
- High-volume features

## Features

- Fast responses
- Lower cost than Gemini Pro
- Text, image, video, audio, and PDF input
- Structured JSON output
