OpenAI GPT-6 Astra is the flagship of the GPT-6 family.

It is a reasoning-heavy, agentic model built for long-running, complex work like coding, computer use, and browser automation, with a 1M-token context window and multimodal input.

## Best For

- Advanced coding assistants
- Long-running agent workflows
- Complex multi-step reasoning
- Apps that work with large documents

## Features

- Strongest reasoning in the GPT-6 family
- Built for agentic, multi-step tasks
- 1M-token context window
- Text and image input
