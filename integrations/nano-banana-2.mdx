Nano Banana 2 is Google's latest image generation and editing model. Upload any image and edit it with plain natural-language instructions, with no layers or masks.

It renders up to 4K, handles text reliably, and accepts up to 14 reference images for style and character consistency.

## Best For

- Photo editing with text prompts
- Consistent characters and styles
- High-resolution images
- Images with text

## Features

- Natural language editing
- Output up to 4K
- Up to 14 reference images
- Lower cost than Nano Banana Pro

## Ask Vibecode

Tell the AI:

> "Add Nano Banana 2 to my app so users can upload a photo and edit it with a text prompt."

The AI will set up the integration automatically.

## Choose This If

Choose Nano Banana 2 for image editing and generation at a lower cost. For the Pro model, see [Nano Banana Pro](/integrations/nano-banana).
